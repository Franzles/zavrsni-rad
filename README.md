Ovaj repozitorij sadrži primjere mrežnih stranica koje koriste odabrane trendove u oblikovanju mrežnih stranica 2025. godine. Mrežne stranice su napravljene u svrhu završnog rada.
Repozitorij se sastoji od sljedećih mrežnih stranica:
*3D - Primjer mrežne stranice koja koristi 3D elemente. Pošto stranica koristi Googleov <model-viewer> mora se pokrenuti pomoću server. Za to se preporučuje Live Server ekstenzija za Visual Studio Code koju se može pronaći ovdje: https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer
*AISite - Primjer mrežne stranice sa slikama generiranim umjetnom inteligencijom. Ideja stranice je početna stranica UI online knjižnice koja vodi prema izvorima informacija za različita područja.
*AnimatedScroll - Primjer mrežne stranice sa animacijama pokrenutim kroz korisničko listanje sadržaja. Pomoću JavaScriptovog IntersectionObserver stranica prati kada 30% područja animiranog elementa bude na zaslonu i tada pokreće animaciju.
*DarkMode - Primjer svijetlog i tamnog načina rada na mrežnoj stranici sa različitim bojama pozadine, teksta i elemenata.
*Glassmorphism - Primjer mrežne stranice koja koristi glassmorphism, odnosno stil matiranog stakla.
*Retro - Primjer mrežne stranice sa retro estetikom. Retro estetika u ovom primjeru se postiže kroz korištenje piksel crteža (eng. pixel art) i "Press start 2P" piksel fonta.
